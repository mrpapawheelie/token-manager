# Credentials

We **validate actions**. We **do not grade people**. Tags are neutral. Grey or empty is a signal, not a blank to fill with a pass. A shady history withholds benefits. **Buyers decide.**

The graph is wider than this one coin. It still sits on the founder's accounts.

## Personal OAuth

`identity_personal_oauth` and `cred_oauth_begin` are stubs for **personal GitHub**, **LinkedIn**, and **personal X**. No token field. GitHub is used later to look at blockchain-aligned contributions on their account. The repo is not moved to a Token Manager org.

## Wallets

`cred_wallet_proof` accepts a public address and nothing else. The method is **Sign-In With Solana**. `signed` and `verified` stay false in Phase 1 because the signature is not checked.

Gitcoin Passport, Build Guild, and Base builders are **not** pasted URLs. `cred_resolve_membership` takes `source` plus the wallet address. The schema has no URL field. The adapter notes say to call the documented API with that signed address. Phase 1 does not call it.

## Tags, not ratings

`identity_list_tags` and `cred_assess` return `CredentialTag` rows:

`new_x_account`, `long_x_silence`, `sudden_launch_posts`, `thin_history`, `gitcoin_passport`, `base_builder`, `build_guild`, `eth_aligned_contrib`.

`cred_assess` does not call a model (`aiCalled: false`). `ratings` is null. A tag turns color only when `recorded` says true. Everything else stays grey. `CredAssessmentResult.gradesPeople` is false.

## Private review

`cred_x_heuristics` watches two patterns: long inactivity then launch spam, and a voice or style shift. A hit becomes an `AdminFlagQueueItem` on the **admin_review** queue.

- `visibility` is `private`
- `published` is false
- `verified` is false
- `autoPublished` is false

The admin shell shows that queue. The public token page does not. The heuristic is not a verified claim.
