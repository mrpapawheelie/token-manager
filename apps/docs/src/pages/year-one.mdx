# Year-one operations

Stage: `year_one_ops`.

The launch week is the loud part. The job is the next twelve months.

`ops_year_checklist` returns the standing list:

- Keep the Meteora lock proof and the team cliff/stream proof on the project site.
- Keep the directory row current: socials, verification, identity methods.
- Post a weekly note a reader can check. Skip price calls.
- Leave dumps alone. Fees already compound into quote token B at `compounding_fee_bps = 10000`. A burn does not undo a dump.
- Run the AMA rhythm. Fee-funded boosts, when they exist, are for attention.
- Re-check Codex after the $1 activation. Keep the key out of git.
- Review co-admins and the guardian policy so the creator wallet is not a single switch.

`ops_year_log_week` appends that week to the local session. If `buybackRequested` is true, the note says the request was discouraged and that no plan was created.

`ai_chat_project` is the placeholder for a later assistant over **public** project context. Phase 1 calls no model. Do not paste keys into it.

`site_preview_pages` lists the public pages: home, launch, locks, directory facts, and admin. `site_publish_proofs` does not deploy anything yet.
