# Pre-launch plan

Do this **before any mint and before any fee**. Tool: `prelaunch_checklist`. It does not block a do-it-yourself launch.

1. **Publish the site.** The contract line is a placeholder: “Contract address publishes at launch.” Nothing is copied until an address exists.
2. **Create the X account** on the founder’s own login.
3. **Publish the account** with the handle, the site, and the launch time.
4. **First AMA.** Name the time in public.
5. **Hype cadence.** A simple posting rhythm through launch week. The dump caveat still belongs on the launch post.

`fee` is `free` and `mint` is `false`. Marketing starts here. Wiring project data to consumers and agents comes later, on the [API builder](/api-builder).

## Site template

Founder sites use a locked stack so they can extend the project after they leave:

- **Vercel**
- **Next.js**
- **TypeScript**
- **shadcn/ui**
- **Zod** for forms

The repo stays on the founder’s GitHub. Token Manager is not the host of record. The directory shell shows the same contract slot: a live mock address with one-click copy, and a pre-mint preview at `/template`.
