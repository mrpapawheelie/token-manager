# Founder site template

This is the stack for the project site. The founder owns the repo and the Vercel project. Token Manager is optional.

- Host: Vercel
- App: latest Next.js (App Router)
- Language: TypeScript
- UI: shadcn/ui
- Forms: Zod

Put the token contract in the first block on the page. One click copies it. Before the mint, show “Contract address publishes at launch” and do not invent an address.

Extend the site in this repo. Leaving Token Manager does not take the site down.
