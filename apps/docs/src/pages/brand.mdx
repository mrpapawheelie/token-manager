# Brand

`brand_principles`, then `brand_generate`. The web preview is `/brand` on the web app. It calls the same renderer as the MCP tool.

## Mark

<ul>
  {BRAND_PRINCIPLES.map((line) => (
    <li>{line}</li>
  ))}
</ul>

The mark is geometric and high contrast: one of four shapes (disc, tile, peak, gem) from the name, on a light or dark field. Words stay in the wordmark on the X header and the OG image. The logo, app icon, avatar, and favicon are the mark alone, so the favicon still reads at 32px.

There is no paid image API and no API key field. `variant` from 0 to 11 picks another shape and palette. {BRAND_ITERATION_NOTE}

## Download

{BRAND_ASSET_OWNERSHIP}

On `/brand`, use the download buttons. Copy the SVG folder into the repository or design folder you control. A host that wants `.ico` can rasterize `favicon.svg`. The source file is the SVG.
