# Naming

Do this before the ticker exists. Tools: `name_intake`, then `name_score` or `name_shortlist`. The domain plan is [Domain](/domain). The files are [Brand](/brand).

Write the target market first. A name that skips that step is a guess, and `name_score` will not mark it preferred.

## Rules

`name_score` and `name_shortlist` use this table. Fewer syllables and fewer letters score higher. A preferred name is one syllable, 2–5 letters, letters only, spellable, recognizable, a clear caller-reported cashtag, not on the local collision list, and it has a market.

Syllables are a vowel-group estimate, not a dictionary. Three of the same letter, or four consonants in a row, fails the spellable check.

## Collision gap

`name_score` does **not** search X. Pass `cashtagTaken: true` when you already know the cashtag collides. Otherwise the tool only checks a built-in list of well-known tickers and generic words.

{NAME_COLLISION_GAP}

`name_shortlist` ranks up to 12 candidates with the same scorer. It requires the market object from `name_intake`. The best row is the highest preferred name, or null when none pass.

Guidance is optional. You can pick a name without these tools. Curve creation still has no platform fee.
